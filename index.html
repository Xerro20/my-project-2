BUILD RELEASE RÉUSSI — ATAS X (.NET 8 / .NET 10)

NQ Autonomous Absorption & Delta Divergence

Stratégie Order Flow 100% autonome compilée en .dll prête à être installée dans ATAS X.

1. DLL Compilée (Directe)

Fichier binaire NqAutonomousAbsorptionStrategy.dll prêt à être copié directement dans le dossier Documents\ATAS\Strategies.

Télécharger NqAutonomousAbsorptionStrategy.dll

2. Pack Complet (.ZIP)

Contient la DLL compilée, l'installateur automatique Windows en 1 clic (Compiler_et_Installer_ATASX.bat), le .csproj et le code C#.

Télécharger le Pack ZIP Complet

3. Code Source & Projet

Code source C# commenté (NqAutonomousAbsorptionStrategy.cs) et fichier projet Visual Studio / Rider (.csproj).

Télécharger le fichier .CS

Installation dans ATAS X en 30 secondes

  1. Téléchargez NqAutonomousAbsorptionStrategy.dll (ou décompressez le pack ZIP et double-cliquez sur Compiler_et_Installer_ATASX.bat).
  2. Placez le fichier NqAutonomousAbsorptionStrategy.dll dans votre dossier :
    %USERPROFILE%\Documents\ATAS\Strategies\
  3. Ouvrez ATAS X, ouvrez un graphique Footprint / Cluster sur NQ ou MNQ, puis ouvrez Chart Strategies (raccourci Ctrl + S).
  4. Sélectionnez NQ Autonomous Absorption & Delta Divergence (Prop Firm Ready), choisissez votre compte (Portfolio), configurez vos paramètres et cochez Active.
